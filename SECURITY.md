# Security Policy — PRANA-AI

## Reporting a Vulnerability

Please report security issues privately via the repository **Security → Advisories** workflow rather than public issue threads.

## Threat Model & Verified Controls

| Threat | Control | Location | Verification |
| :--- | :--- | :--- | :--- |
| **API key exposure** | `GEMINI_API_KEY` / `GEMINI_API_KEYS` and `PRANA_BUNDLE_SECRET` (`>= 32` bytes enforced in deployed envs) are read strictly in server modules; never bundled into `frontend/` (`VITE_*`). | `backend/gemini_client.py`, `backend/safety.py` | Vite client build isolation & test suite |
| **Client-side evidence tampering & replay** | Server signs every `EvidenceBundle` with HMAC-SHA256 (`PRANA_BUNDLE_SECRET`, isolated from `GEMINI_API_KEY`) including a `6h` `issued_at` TTL window; `/v1/chat` enforces bounded JSON bodies (`512 KB`), rate-limits invalid/forged/malformed requests (`429`), and rejects tampered, unsigned, or expired bundles (`403`). | `backend/safety.py`, `backend/schemas.py`, `backend/request_guards.py`, `backend/main.py` | `backend/tests/test_safety.py`, `test_api.py`, `test_request_guards.py` |
| **LLM number fabrication & unsafe claims** | Post-generation validator checks unit-bound values, explicit AQI/$\text{PM}_{2.5}$ statements, unanchored standalone numbers (exact 1-decimal/integer rounding), multilingual medical dosing/diagnosis prohibitions (EN/Hinglish/Indic, fail-closed on dosing prose), and sub-clause-scoped English/Indic banned-claim patterns ("safe window", houseplants); Vision room-audit outputs share the claim/plant checks and cap tips at `Rs 0–500`; rejections fall back to deterministic templates. Pre-LLM emergency triage (`108/112` across 8 Indian languages) and post-generation regex rules serve as best-effort heuristic defense-in-depth rather than full clinical NLU, paired with persistent UI `108/112` emergency notices. | `backend/safety.py`, `backend/fallbacks.py`, `backend/engine.py`, `backend/explainer.py` | `backend/tests/test_safety.py`, `test_explainer.py` |
| **Proxy IP spoofing & quota/endpoint abuse** | Forwarding headers are scoped strictly by proxy mode (`VERCEL`, `RENDER`, or `TRUST_PROXY_HEADERS=1`); per-IP sliding-window limiters guard both LLM (`120 req/60s`) and non-LLM/read routes (`90 req/60s` including `skip_llm=true`, `/v1/air`, `/v1/geocode`, `/v1/reverse-geocode`) without evicting active blocked buckets on saturation, backed by paired India coordinate validation (`6.0..37.5 N`, `68.0..97.5 E`), `0.25°` weather cache alignment, and geocode caching. | `backend/request_guards.py`, `backend/main.py`, `backend/schemas.py`, `backend/data_fetcher.py` | `backend/tests/test_request_guards.py`, `test_data_fetcher.py`, `test_api.py` |
| **Cross-site request abuse (CSRF quota theft)** | Browser GET/POST API requests carrying an unallowlisted or cross-host `Origin` header (validated against `Host` / `request.url.netloc`, ignoring spoofable `X-Forwarded-Host`) are rejected with `403`. | `backend/request_guards.py`, `backend/main.py` | `backend/tests/test_request_guards.py`, `backend/tests/test_api.py`, `scripts/smoke.py` |
| **Malicious image upload / EXIF leak / DoS** | Middleware validates `Origin`, IP rate limit, `Content-Length`, and bounded streaming `5 MB` chunk reading (`403`/`429`/`413`) **before** multipart parsing; strict JPG/PNG/WebP MIME & Pillow verification (`415`), `Image.MAX_IMAGE_PIXELS = 25_000_000` bomb cap, `ImageOps.exif_transpose()` rotation, EXIF strip, and bounded prompt fields (`current_naqi` `0..500`, sanitized `city`/`area_name`). | `backend/image_audit.py`, `backend/request_guards.py`, `backend/explainer.py` | `backend/tests/test_api.py` |
| **XSS, clickjacking & MIME sniffing** | Strict CSP (`script-src 'self'`, `object-src 'none'`, `frame-ancestors 'none'`), HSTS preload, COOP `same-origin`, `nosniff`, `X-Frame-Options: DENY`, `Cache-Control: no-store` on API responses, and `X-Request-Id` log correlation. | `vercel.json`, `backend/request_guards.py` | `backend/tests/test_request_guards.py`, `scripts/smoke.py` |
| **Dependency vulnerabilities** | Pinned patched runtime packages (`fastapi==0.165.0`, `starlette==1.10.0`, `pillow==13.0.0`, `python-multipart==0.0.31`, `python-dotenv==1.2.2`) gated by full transitive `pip-audit` and `npm audit --omit=dev`. | `backend/requirements.txt`, `.github/workflows/ci.yml` | CI workflow |

## Known Operational & Privacy Notes

- In-memory rate limiting and the Open-Meteo/geocode TTL caches (`900s`, `256` entries) operate per serverless/container instance.
- Ensure `PRANA_BUNDLE_SECRET` is configured in Render and Vercel environment variables so evidence signatures persist consistently across restarts and horizontal replicas.
- **Data Privacy (DPDP alignment):** Household member names/ages/health conditions stay in browser `localStorage` unless submitted for a session plan; LLM prompt serialization replaces household member names with generic aliases (`Household Member 1`, etc.), optional GPS coordinates are sent ephemerally for Open-Meteo / BigDataCloud lookup, and optional EXIF-stripped room photos are processed ephemerally via Google Gemini Vision without server storage.
